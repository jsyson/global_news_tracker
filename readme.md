# Global News Tracker (GSS)

## 🌟 앱 소개
글로벌 서비스(Amazon, Google, YouTube 등)의 장애 현황을 한눈에 파악하고, 관련 뉴스를 실시간으로 추적할 수 있는 지능형 모니터링 대시보드입니다.

## 🚀 주요 기능
1. **실시간 모니터링**: Downdetector 데이터를 기반으로 미국(US) 및 일본(JP)의 주요 서비스 상태를 실시간으로 추적합니다.
2. **지능형 뉴스 검색**: 장애가 감지된 서비스(Danger/Warning 상태)에 대해 Google News에서 실시간 기사를 백그라운드에서 자동으로 검색합니다.
3. **시각적 알림**: 뉴스 검색 결과가 있을 경우, 서비스 버튼 우측 상단에 세련된 **숫자 배지**가 표시됩니다. 배지를 클릭하면 즉시 뉴스 내용을 확인할 수 있습니다.
4. **자동 화면 전환 (Dashboard Switcher)**: 설정된 주기에 따라 미국과 일본 대시보드가 자동으로 전환됩니다. 대형 모니터에 띄워두는 **관제용 화면**으로 최적화되어 있습니다.
5. **컴팩트 정렬 디자인**: 이슈가 발생한 서비스를 최상단에 자동 배치하며, 바둑판 모양의 정렬로 한 화면에서 수십 개의 서비스를 동시에 감시할 수 있습니다.

## 🛠 처음 사용자를 위한 가이드

### 1. 파이썬(Python) 설치
- [Python 공식 홈페이지](https://www.python.org/downloads/)에서 최신 버전을 다운로드하여 설치합니다.
- **중요**: 설치 과정 중 **"Add Python to PATH"**라는 체크박스가 나오면 반드시 체크해야 합니다.

### 2. 라이브러리 설치 (최초 1회)
이 프로젝트 폴더를 열고, 터미널(또는 명령 프롬프트) 창에 아래 명령어를 복사하여 입력합니다.
```bash
pip install -r requirements.txt
```

### 3. 프로그램 실행
터미널에서 아래 명령어를 입력하면 자동으로 웹 브라우저가 열리며 대시보드가 실행됩니다.
```bash
streamlit run main.py
```

## 📊 대시보드 읽는 법
- **빨간색/주황색 버튼**: 장애가 발생했거나 서비스가 불안정한 상태입니다.
- **초록색 버튼**: 서비스가 정상적으로 운영되고 있습니다.
- **회색 버튼**: 데이터 수집에 실패했거나 리포트가 없는 상태입니다.
- **숫자 배지 (Neon Red)**: 해당 서비스의 장애와 관련된 최근 뉴스 개수입니다.
- **차트**: 지난 24시간 동안 사용자로부터 접수된 장애 리포트 추이입니다.

## 📁 프로젝트 구조
- `main.py`: 전체 앱의 시작 파일
- `pages/`: 대시보드(미국/일본) 및 뉴스 상세 페이지 구성
- `config.py`: 타이머 주기, 감시 목록, 뉴스 검색 등 핵심 설정 및 공용 함수
- `dashboard_dd.py`: 대시보드 화면 렌더링 및 인터랙션 로직
- `get_downdetector_web.py`: 웹 자동화 도구(Selenium)를 이용한 데이터 수집 엔진
- `requirements.txt`: 프로젝트 실행에 필요한 라이브러리 목록
